# Local bottle assembly and verification

Versioned recipes preserve previous deliveries and the current Switchboard 2.0.2/Folio 1.1.2 public installation release. They build standard Homebrew bottles from independently verified prebuilt archives; they do not claim compilation by Homebrew. Runtime contents are checked before and after packaging. The source, platform and archive identities are explicit inputs or release-specific pins.

Provide `--archive`, `--sha256`, `--target`, `--tag`, `--formula`, `--receipt`, `--strategy ../lib/github_private_release_download_strategy.rb` and `--output-dir`. Switchboard also needs `--wrapper switchboard-homebrew-wrapper.sh`. The 1.1.1 and 1.1.2 Folio recipes additionally require `--version` and `--source-commit`. The 2.0.1 and 2.0.2 Switchboard recipes additionally require exact expected version, source commit, source SHA-256, CLI SHA-256, recipe SHA-256 and the installation release repository. Run `--help` for exact arguments. The receipt must come from the actual target Homebrew context; never relabel translated execution as native. Output includes the bottle, checksum and assembly receipt. Switchboard also emits its complete payload inventory.

The exact clean assembly formulas and archive inventories are preserved in `../assembly/`. Pass those formula templates to `--formula`; they contain no bottle block. Generate a new clean source formula from the product's reviewed four-platform archive inventory when changing versions. Never use the final shipping formula as an assembly input, because it would embed stale bottle digests. Once all bottles are built, generate the shipping formula from their exact checksums. Current public formulas use Homebrew's standard HTTPS downloader. Historical private recipes keep their helper in `lib/`; each embedded keg has a copy in `.brew/lib`, avoiding global-prefix collisions. New bottles may preserve that unused metadata helper, but their formulas neither require it nor select the private strategy.

Test normal Homebrew installation, both products together, formula behavior, installed-formula loading and complete post-pour runtime integrity in isolated prefixes. `verify-installed-formula.rb` exercises Homebrew's actual fallback loader. On a host whose `brew test` command refuses compiler setup before tests, `formula-test-without-compiler.rb` runs the unchanged formula test block through Homebrew's own API. Report this distinction; do not call it a successful stock `brew test` invocation.

All application build inputs, raw acceptance identity and platform scopes are recorded in the products' release evidence. GitHub Actions is disabled. No service or live user workspace is needed for validation.
